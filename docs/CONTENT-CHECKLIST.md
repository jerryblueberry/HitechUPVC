# Content Checklist

Assets and copy still needed before launch. Mark items as gathered in TRACKING or here.

## Product Data

- [ ] Full product list per category (windows / doors / panels) with slugs
- [ ] Opening type per product (sliding, casement, tilt-turn, folding, French, bay/bow)
- [ ] Profile system specs: frame depth, chamber count, U-value, glazing thickness
- [ ] Available colors/finishes (foil woodgrain, RAL colors, dual-color) + swatch images
- [ ] Warranty terms per product line
- [ ] Certifications (ISO, CE marking, fire rating, local building codes)

## Media

- [ ] Professional photography: hero, lifestyle, macro hardware
- [ ] Cross-section diagrams/renders of profiles
- [ ] Before/after renovation photos
- [ ] Short product demo videos or GIFs (opening/closing mechanism)
- [ ] Company/factory photos
- [ ] Team photos, founder story

## Trust Content

- [ ] Client testimonials (name, project type, photo, star rating)
- [ ] Case studies / completed projects with location, product, images
- [ ] Awards, years in business, installation counts
- [ ] Google / Trustpilot rating if available

## Business / Functional

- [ ] Service areas / branches / showroom addresses
- [ ] Pricing model or "starting from" ranges
- [ ] Contact channels (WhatsApp, phone, email)
- [ ] Quote form fields (product type, dimensions, color, budget, location)
- [ ] FAQs (maintenance, installation time, lifespan, vs aluminum/wood)

## SEO / Meta
